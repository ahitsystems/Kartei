# Security policy

## Supported versions

Only the latest release gets security fixes. Please upgrade before reporting; the nightly images are for testing only.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/ahitsystems/Kartei/security/advisories/new), not as a public issue. Include the version, the affected area and steps to reproduce, but no real contact data or credentials.

You'll get an answer within a week. Once a fix is released, the advisory is published with credit to you, unless you prefer otherwise.
