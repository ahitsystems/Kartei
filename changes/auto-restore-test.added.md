- **Automatic restore test:** after the nightly backup, Kartei restores it into a scratch database every 7 days and compares it with the live one (*Settings → Backup → Automatic restore test: interval (days)*, 0 = on request only). Monitoring now warns when the last successful test is older than the interval plus two days, not only when a test failed. Migration 0022. With your own PostgreSQL server, the database user needs `CREATEDB` for the test; without it, monitoring will start to warn after the update: grant it, or set the interval to 0.
